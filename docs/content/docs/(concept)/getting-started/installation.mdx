## パッケージのインストール

Chlorophyllをインストールしてください。

```bash
pnpm add @morinoparty/chlorophyll-react
```

プリセットはPanda CSS v2を必要とします。peer dependencyとして`@pandacss/dev`、`@pandacss/preset-base`、`@pandacss/types`（いずれも2.x）をインストールしてください。

```bash
pnpm add -D @pandacss/dev@^2 @pandacss/preset-base@^2 @pandacss/types@^2
```


## Panda CSSの設定

ChlorophyllはPanda CSSを使用しています。プロジェクトにPanda CSSがまだ設定されていない場合は、[Panda CSS公式ガイド](https://panda-css.com/docs/overview/getting-started)を参照してください。

`panda.config.ts`にChlorophyllのプリセットを追加します。

```ts title="panda.config.ts"
import { defineConfig } from '@pandacss/dev';
import { createPreset, stone } from '@morinoparty/chlorophyll-react/preset';

export default defineConfig({
  preflight: true,
  presets: ['@pandacss/preset-base', createPreset({ brandColor: 'mori', grayColor: stone, radius: 'md' })],
  include: ['./src/**/*.{js,jsx,ts,tsx}'],
  outdir: 'styled-system',
});
```

## CSSの生成

設定が完了したら、Panda CSSを実行してスタイルを生成します。

```bash
pnpm panda codegen
```
