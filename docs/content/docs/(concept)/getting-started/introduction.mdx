Chlorophyllのドキュメントへようこそ。

## インストール

```bash
pnpm add @morinoparty/chlorophyll
```

## クイックスタート

パッケージからコンポーネントをインポートして使用します。

```tsx
import { Button } from '@morinoparty/chlorophyll-react';

export function App() {
  return <Button>Click me</Button>;
}
```
